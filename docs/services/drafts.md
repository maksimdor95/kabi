# Модуль: drafts

## 1. Назначение
Помогает действовать: генерирует черновики откликов, сопроводительных писем, заявок
на CFP под конкретную возможность и профиль. «Менеджер готовит бумаги за звезду».

## 2. Этап
M4.

## 3. Публичный интерфейс
```python
async def draft_for_opportunity(profile, opportunity) -> str: ...
async def draft_application(profile, opportunity) -> str: ...
async def draft_cfp_pitch(profile, opportunity) -> str: ...
```
Роутинг: `opportunity.type == "talk"` → CFP-питч, иначе отклик на вакансию.

## 4. Входы / Выходы
- **Вход:** профиль + выбранная возможность (из callback `draft:{match_id}`).
- **Выход:** текстовый черновик (пользователь редактирует и отправляет сам).

## 5. Зависимости
- **Внутренние:** `app/llm` (tier `primary`), `app/services/profile.profile_to_text`.
- **Внешние:** —

## 6. Данные
Читает `Profile`, `Opportunity`. Черновики в БД не пишем (MVP).

## 7. Guardrails / ограничения
- Только черновик; **не отправляет** ничего от имени пользователя.
- Только факты из профиля; без выдуманного опыта.
- В тексте явно: это черновик, отправить нужно самому.

## 8. Тесты / evals
- **Тест:** с моком LLM промпт содержит роли профиля и title возможности.
- **Eval (ручной/LM-judge):** нет выдуманных фактов.

## 9. Открытые вопросы
- Тон по умолчанию: деловой русский; при необходимости EN позже.

## 10. Статус
M4: реализованы `draft_application` / `draft_cfp_pitch` + кнопка «✍️ Черновик» на карточке.
