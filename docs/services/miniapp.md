# Модуль: miniapp (Telegram Mini App, M11)

## 1. Назначение
Богатый UI поверх того же ядра, что и бот: подборки, избранное, профиль —
списком с фильтрами, а не лентой сообщений. Бот остаётся основным каналом
(проактивные пуши), Mini App — «рабочий стол» для разбора накопленного.

## 2. Границы
- `app/api/` — **тонкий транспорт**: auth, валидация запроса, DTO. Как `bot/`:
  никакой бизнес-логики (hard rule №1). Всё через `app/services/*`.
- `web/` — статика (HTML/CSS/JS без сборки). Никаких секретов, никаких прямых
  обращений к БД/LLM.
- Ядро (`app/services`, `app/db`) о существовании Mini App не знает.

## 3. Аутентификация

Источник истины — `Telegram.WebApp.initData` (подписанная строка от клиента).

Заголовок запроса: `Authorization: tma <initData>`.

Проверка (`app/api/auth.py`, чистая функция, без FastAPI):

1. `parse_qsl(init_data, strict_parsing=True)` — **сырые** значения, без
   повторного кодирования.
2. `data_check_string` = все пары **кроме `hash`**, `key=value`, отсортированы
   по ключу, склеены `\n`.
   Поле `signature` (Bot API 7.2+) **входит** в строку: по документации Telegram
   `hash` — «hash of all passed parameters», а `signature` — «signature of all
   passed parameters (except hash)», то есть считается раньше `hash`.
   Исключение `signature` — правило только для Ed25519-проверки третьей стороной.
3. `secret_key = HMAC_SHA256(key="WebAppData", msg=bot_token)`.
4. `hex(HMAC_SHA256(key=secret_key, msg=data_check_string)) == hash`,
   сравнение через `hmac.compare_digest`.
5. `auth_date` обязателен и не старше `MINIAPP_AUTH_TTL_SECONDS` (по умолчанию 24 ч).
6. Поле `user` обязательно и должно содержать `id` — иначе отказ.

Ошибки → `401` с машинным кодом: `malformed`, `no_hash`, `bad_signature`,
`no_auth_date`, `expired`, `no_user`, `not_configured`.

**Guardrails**
- `initDataUnsafe` с клиента не используется никогда — только проверенный `initData`.
- `telegram_id` берётся **только** из проверенной подписи, не из тела запроса.
- Токен бота в браузер не попадает; `initData` не логируем (в логах только `tg_id`).
- Same-origin: статика и API на одном домене, CORS-middleware нет намеренно.

## 4. Контракт API

Базовый префикс `/api/v1`. Все ручки, кроме `/health` и `/api/v1/config`,
требуют валидный `Authorization: tma …`.

| Метод | Путь | Смысл |
|-------|------|-------|
| `GET` | `/health` | liveness (без auth) |
| `GET` | `/api/v1/config` | публичный конфиг UI (без auth) |
| `GET` | `/api/v1/me` | профиль: роли, навыки, готовность, шаг онбординга |
| `GET` | `/api/v1/feed?scope=jobs\|pitch\|talks&limit=` | подборка **из БД**, без ingest |
| `POST` | `/api/v1/feed/refresh` | подборка **с ingest** (долго, отдельная кнопка) |
| `GET` | `/api/v1/saved` | избранное |
| `POST` | `/api/v1/matches/{id}/reaction` | `{"reaction": "up\|down\|save\|unsave\|hide"}` |
| `POST` | `/api/v1/matches/{id}/draft` | черновик отклика/заявки (LLM) |

Коды: `200`, `401` (auth), `403` (чужой match), `404` (нет профиля/матча),
`409` (профиль не готов к подбору), `422` (валидация), `429` (rate limit).

`GET /feed` намеренно не ходит в сеть: открытие Mini App должно быть мгновенным.
Свежие данные — `POST /feed/refresh` (та же логика, что `/today` в боте) или
ночной scheduler.

## 4b. Правила UI

- **У каждого действия подпись.** Голая иконка без текста запрещена: цена ошибки
  («Скрыть» вместо «В избранное») выше, чем выигрыш в компактности.
- **Иконки монохромные штриховые** (inline SVG, `currentColor`) — наследуют тему
  Telegram и не спорят с ней цветом. Эмодзи в интерфейсе не используем.
- Правки профиля, CV, ссылок и расписания живут в чате. Экран «Профиль» их не
  прячет: список «Это делается в чате» объясняет, что и какой командой, и по
  тапу закрывает приложение обратно в диалог.

## 5. Изоляция (MU-A)
Профиль резолвится из `telegram_id` подписи. Реакция и черновик передают
`actor_profile_id` — чужой `match_id` даёт `403`, состояние не меняется
(см. `docs/services/multiuser.md`).

## 6. Rate limit
In-process token bucket на `telegram_id` для дорогих ручек:
`feed/refresh` и `draft` — 5 запросов / 5 минут. Превышение → `429`.
Цель — не защита от DDoS, а предохранитель от залипшей кнопки и трат на LLM.

## 7. Конфиг (env)

| Переменная | Назначение |
|------------|------------|
| `MINIAPP_ENABLED` | включить API и кнопку в боте (по умолчанию `false`) |
| `MINIAPP_URL` | публичный `https://` URL Mini App (для кнопки в боте) |
| `MINIAPP_AUTH_TTL_SECONDS` | срок годности `initData`, по умолчанию `86400` |

Без `MINIAPP_URL` бот кнопку не показывает — Telegram принимает только HTTPS.

## 8. Развёртывание
Отдельный процесс `uvicorn app.main:app` (systemd `kabi-api`) на `127.0.0.1:8080`,
снаружи — Caddy с автоматическим Let's Encrypt (`deploy/Caddyfile`).
Бот (`kabi-bot`) остаётся отдельным юнитом: падение UI не роняет пуши.

## 9. Тесты / evals

| ID | Критерий |
|----|----------|
| A1 | Валидный `initData` → `200`, распознан правильный `telegram_id` |
| A2 | Подменённое поле при том же `hash` → `401 bad_signature` |
| A3 | `auth_date` старше TTL → `401 expired` |
| A4 | Нет `hash` / кривая строка → `401` |
| A5 | Чужой токен бота → `401 bad_signature` |
| A6 | `initData` с `signature` (Bot API 7.2+) проходит проверку |
| A7 | Нет заголовка `Authorization` → `401` |
| M1 | `/feed` не вызывает ingest (`do_ingest=False`) |
| M2 | Реакция на чужой match → `403`, статус чужого матча не изменился |
| M3 | `/saved` возвращает только свои матчи |
| M4 | `/me` без профиля → `404` с шагом онбординга |
| M5 | Профиль не готов → `/feed` даёт `409`, а не пустой список |

Файлы: `tests/test_miniapp_auth.py`, `tests/test_miniapp_api.py`.

## 10. Вне scope v1
Редактирование профиля и расписания из UI (пока в боте: `/profile`, `/schedule`),
загрузка CV через Mini App, push-уведомления из UI, оплата, шаринг карточек.

Причина не только в объёме: файл и ссылки естественнее отдавать в чат, а
`sendData` из Mini App доступен только при запуске с кнопки клавиатуры — у нас
вход через меню-кнопку. Поэтому UI честно отправляет в чат, а не имитирует
загрузку.

## 11. Статус
M11 v1: auth + `/me` · `/feed` · `/saved` · реакции · черновики + статика `web/`,
кнопка меню и `/app` в боте.
