# Модуль: persistence (app/db)

## 1. Назначение
Хранилище и модели данных: SQLAlchemy-модели, сессии БД, миграции, репозитории.
Это «долговременная память» агента.

## 2. Этап
M1.

## 3. Публичный интерфейс
```python
# app/db/models.py   — ORM-модели (User, Profile, Opportunity, Match, Feedback)
# app/db/session.py  — async engine + session factory
# репозитории/запросы, включая pgvector-поиск ближайших
```

## 4. Входы / Выходы
- **Вход:** доменные объекты для сохранения; запросы.
- **Выход:** сохранённые/прочитанные сущности.

## 5. Зависимости
- **Внешние:** PostgreSQL + pgvector, SQLAlchemy, asyncpg.

## 6. Данные
Владеет всеми сущностями из `docs/architecture/data-model.md`.

## 7. Guardrails / ограничения
- Домен (`app/domain`) не зависит от этого модуля (зависимость направлена внутрь).
- Миграции версионируются; уникальный индекс `(source, external_id)` для дедупа.

## 8. Тесты / evals
- **Тест:** CRUD сущностей; pgvector-поиск возвращает ближайших.
