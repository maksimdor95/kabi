# Sprint B — качество вакансий (staging first)

## Цель
Карточка и подборка не стыдные рядом с Getmatch: понятный матч, без мусора и ярлыков.
Прод не трогаем, пока нет явного «Ок».

## B0. Карточка менеджера (сейчас)
Шаблон job:
```
Product Owner
🏢 MAREE
📍 Москва · удалённо
[💰 вилка, если есть]

Суть: …
О компании: …   # только если есть факт из описания
О продукте: …   # только если есть факт из описания

Почему ты:
· <матч #1 — самый сильный сигнал>
· <матч #2>
· <матч #3>

<blockquote expandable>описание из источника</blockquote>
Открыть вакансию →
```

Правила:
- «Почему ты» = приоритезированные причины матча (роль/грейд → домен → навыки → формат → ЗП).
- Не писать риски / «оговорок нет» / ярлыки апсайд·якорь·оговорка·upside.
- Пустые «о компании/продукте» — строку не рисуем (web-enrich компаний — позже, не в B0).
- Цитата = текст источника, не дубль «Сути».
