# Rubric E2 — объяснение «почему ты» (evals.md §8.2)

Оценка `reason` по шкале 0–2 на критерий. Сумма 0–8.

| ID | Критерий | 0 | 1 | 2 |
|----|----------|---|---|---|
| R1 | Факты | Выдумка | Натяжка | Только факты из профиля/карточки |
| R2 | Специфика | Вода | 1 якорь | ≥2 якоря |
| R3 | Честность fit | Игнор мисфита | Частично | Честно |
| R4 | Полезность | Не помогает | Слабо | Понятно зачем открывать |

Авто-fail R1=0: факты, которых нет во входах.
Fallback matching («Совпадение по роли…») → R2=0, R1 не штрафуем.
