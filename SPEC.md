# Kabi — продуктовая спецификация MVP

## 1. Vision
Персональный AI-менеджер карьеры в Telegram, который знает о пользователе всё
релевантное и **проактивно** приносит подходящие вакансии и приглашения на
выступления/конференции — как персональный менеджер у звезды.

## 2. Scope MVP
- **Один пользователь** (жена автора). Multi-user откладываем.
- **Вход в профиль:** загрузка CV/резюме (PDF/DOCX) + уточняющий диалог.
- **Типы возможностей:** (1) вакансии/работа, (2) выступления/конференции.
- **Интерфейс:** Telegram-бот (`aiogram`) + Mini App (M11, `docs/services/miniapp.md`).

## 3. Пользовательские боли
- Нет времени мониторить площадки.
- Много нерелевантного шума.
- Пропуск дедлайнов (CFP конференций, отклики).
- Нет проактивного «толчка» с релевантными возможностями.

## 4. Core Loop (агентный цикл)
```
1. ЗНАТЬ     → профиль из CV + диалога
2. ИСКАТЬ    → мониторинг источников (вакансии, CFP/конференции)
3. МЭТЧИТЬ   → эмбеддинги + фильтры + ранжирование
4. ПРИНОСИТЬ → ежедневная подборка + объяснение «почему это ты»
5. УЧИТЬСЯ   → реакции 👍/👎/скрыть уточняют профиль
```

## 5. Данные о пользователе
- **CV parsing:** навыки, опыт, роли, локация, языки, цели.
- **Enrichment (M1):** обогащение профиля из публичных источников пользователя (HH,
  LinkedIn, записи выступлений) — по его ссылкам и с явного согласия. См. `enrichment.md`.
- **Диалог-онбординг:** менеджер сначала делает домашку, потом задаёт минимум вопросов.
  5 обязательных: приоритет, **зарплата (обязательна)**, статус поиска, красные флаги,
  готовность выйти. Дефолт приоритета — **«оба, вакансии первыми»**. Полный сценарий —
  в `dialogue-agent.md`, контракт готовности профиля — в `profile.md`.
- **Принцип:** собираем данные только о самом пользователе и с его согласия.

## 6. Источники возможностей
- **Вакансии:** официальные API job-boards, RSS/агрегаторы.
- **Выступления/конференции:** CFP-агрегаторы, сайты конференций, профильные каналы.

## 7. Мэтчинг
- Эмбеддинги профиля и возможностей → векторное сходство (`pgvector`).
- Хард-фильтры: локация, remote, язык, зарплатный минимум, дедлайн.
- Ранжирование + порог релевантности.
- LLM генерирует объяснение «почему подходит».

## 8. Проактивность
- Scheduler раз в день гоняет core loop.
- «N возможностей на сегодня» с карточками и кнопками 👍/👎/💾/скрыть.
- Напоминания о дедлайнах (M3).

## 9. Метрика успеха MVP
Пользователь открывает ежедневную подборку и говорит «это реально про меня»
(высокий CTR/positive-feedback rate по карточкам). Если да — гипотеза жива.

## 10. Не в scope MVP
SaaS-мультитенантность, биллинг, success fee, скрапинг данных о третьих лицах.
Несколько Telegram-профилей в одном боте (**MU-A**) — поддерживается:
см. `docs/services/multiuser.md`.
